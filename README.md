# OverlayHUD — Multiplayer Fix \& Ultimate Optimization



> \*\*Оригинальный автор:\*\* \[Dunweir](https://github.com/Dunweir/OverlayHUD-repo)
> Изначально этот мод был разработан другим человеком исключительно под одиночную игру (или для хоста). Данный репозиторий — это форк (доработка), созданный для адаптации мода под мультиплеер и радикального улучшения его производительности.



Это полностью переработанная и оптимизированная версия мода OverlayHUD для игры R.E.P.O. Оригинальный мод отлично справлялся со своей задачей, но имел критические баги для подключившихся игроков (клиентов) и вызывал сильные просадки FPS.



Наш фикс исправляет все эти проблемы и делает интерфейс идеально гладким для всех игроков в лобби.



## 🛠 Что нового и исправленного:

* **Полная поддержка клиентов (Multiplayer Fix):** Оверлей теперь корректно активируется у всех подключившихся игроков сразу после загрузки уровня.
* **Синхронизация здоровья (HP Fix):** Убраны "прыжки" и задержки полоски здоровья при нанесении урона мобам. Здоровье отнимается плавно и корректно у всех игроков.
* **Динамические таймеры КД:** Отсчет времени возрождения монстров (черепки) теперь честно синхронизируется с хостом. Больше никаких зависаний таймера.
* **Ultimate Optimization (Пинг и ФПС):**

  * Полностью переписана логика `Reflection` в коде плагина. Добавлено кэширование, которое убирает спайки GC (остановки сборщика мусора). Пинг больше не скачет.
  * Убраны тяжелые графические фильтры `drop-shadow` в CSS, которые сильно нагружали видеокарту.
  * Интервалы сканирования карты увеличены, что значительно снижает фоновую нагрузку на процессор.
* **Умное скрытие (Smart Auto-Hide):** Оверлей элегантно скрывается при `Alt-Tab` (потере фокуса), но игнорирует системные уведомления Windows и не мерцает при кликах по собственному меню настроек благодаря проверкам через Win32 API.



## 📦 Установка

1. Установите [BepInEx](https://github.com/BepInEx/BepInEx).
2. Скачайте последний релиз из раздела **Releases** справа.
3. Распакуйте архив.
4. Поместите файл `OverlayHUD.dll` и архив `OverlayHUD\_app.zip` в папку `BepInEx/plugins`.
5. Готово! Запускайте игру (убедитесь, что играете в оконном режиме без рамки / Borderless).

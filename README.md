# OverlayHUD — Multiplayer Fix & Ultimate Optimization

> **Оригинальный автор:** [Dunweir](https://github.com/Dunweir/OverlayHUD-repo)  
> Изначально этот мод был разработан исключительно под одиночную игру (или для хоста). Данный репозиторий — это форк (доработка), созданный для адаптации мода под мультиплеер и радикального улучшения его сетевой и локальной производительности.

Это полностью переработанная и оптимизированная версия мода OverlayHUD для игры R.E.P.O. Оригинальный мод отлично справлялся со своей задачей, но имел критические баги для подключившихся игроков (клиентов) и вызывал сильные просадки FPS и пинга. 

Наш фикс решает все эти проблемы и делает работу интерфейса идеально гладкой для всех игроков в лобби.

## 🛠 Что нового и исправленного:

* **Полная поддержка клиентов (Multiplayer Fix):** Оверлей теперь корректно активируется у всех подключившихся игроков сразу после загрузки уровня, включая магазин. Скрывается на Арене, чтобы не мешать дуэлям.
* **Глобальная синхронизация (Photon Events):** Игроки с установленным оверлеем теперь общаются по невидимому защищенному каналу. Если один игрок обнаружил монстра, он появится в оверлее у всей команды. Хост также делится с клиентами точным таймером респавна до миллисекунд.
* **Честные таймеры КД:** Если игра не передает точное время возрождения монстра, мод больше не ставит фейковые 60 секунд. Вместо этого клиенту честно показывается иконка черепа (💀) без таймера.
* **Синхронизация здоровья (HP Fix):** Убраны "прыжки" и задержки полоски здоровья при нанесении урона. Здоровье отнимается плавно и корректно у всех игроков.
* **Ultimate Optimization (Пинг и ФПС):**
  * Сетевые HTTP-запросы плагина переведены на технологию `Keep-Alive`. Мод больше не спамит тысячами TCP-соединений, что полностью устраняет скачки пинга и падение FPS в мультиплеере.
  * Полностью переписана логика `Reflection`. Добавлено кэширование, которое убирает микрофризы из-за сборщика мусора (GC). 
  * Интервалы сканирования карты оптимизированы для снижения фоновой нагрузки на процессор.
* **Умное скрытие (Smart Auto-Hide):** Оверлей элегантно скрывается при `Alt-Tab` (потере фокуса), игнорирует системные уведомления Windows и не мерцает при кликах по собственному меню настроек.

## 🛠 Установка

### Требования
* Установленный и настроенный **BepInEx** (версии 5.x).

### Способ 1: Автоматическая установка через менеджеры модов (Рекомендуется)

**Для пользователей Gale:**
1. Нажмите кнопку **Import** на верхней панели.
2. Выберите **Local mod** и укажите скачанный установочный `.zip` архив мода. 
3. Зависимости (BepInExPack) скачаются автоматически. Нажмите *Launch modded*.

**Для пользователей Thunderstore / r2modman:**
1. Скачайте установочный `.zip` пакет мода из раздела **Releases**.
2. Откройте менеджер и выберите ваш профиль с игрой R.E.P.O.
3. Перейдите во вкладку **Settings** (Настройки) -> **Import local mod** (Импортировать локальный мод).
4. Выберите скачанный `.zip` пакет. Менеджер всё установит сам!

### Способ 2: Ручная установка (в папку профиля)
1. Скачайте файлы `OverlayHUD.dll` и `OverlayHUD_app.zip` из раздела **Releases**.
2. В Thunderstore выберите профиль игры, перейдите в **Settings** и нажмите **Browse profile folder** (Открыть папку профиля).
3. Перейдите по пути `BepInEx\plugins\`.
4. Создайте новую папку для мода. Назовите её коротко (например, `OverlayHUD`).
   > ⚠️ **Важно:** В Windows есть ограничение на длину пути (260 символов). Если название папки будет слишком длинным, оверлей не сможет распаковать свои файлы и не появится на экране. Ошибка `0x80010135`.
5. Поместите оба скачанных файла в эту папку. 
6. **Не распаковывайте `OverlayHUD_app.zip` вручную!** Просто запустите игру, и плагин сам извлечет локальный сервер.

### ❓ Как проверить, что всё работает?
Запустите игру. При старте в черном окне консоли BepInEx должна появиться строка:
`[Info   :OverlayHUD] OverlayHUD is running.`
При загрузке в лобби или на уровень на экране появится интерфейс оверлея.
